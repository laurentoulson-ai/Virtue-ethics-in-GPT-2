# PILOT: Virtue-ethics-in-GPT-2
An initial mech interp project to identify virtue ethics specialisation in GPT-2

- This is a short pilot project where I played around with mech interp techniques to learn more about how mech interp could be used to investigate moral decision making in AI model
- This project was playful and investigative for the purposes of learning and exploration - it was not intended to be academically rigorous
- See repository 'Moral-decision-making-GPT2' for a fully developed, rigorous version of this pilot
